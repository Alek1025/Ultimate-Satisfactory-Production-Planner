Opus R4:
Mod eval. Gains: live data (real belt rates, machine states, power) instead of 5-min autosave inference; in-world markers/ghost outlines of sites, corridors, node claims; no alt-tab. Costs: SML historically lags weeks-months after major patches (planner dead for updaters), vs save parser you can fix same-day alone; Unreal C++/Blueprint toolkit is a separate codebase from TS+LP; HiGHS-level solving + rich map in Unreal UI is a big job; PC only (Steam/Epic), excludes console and non-modders; multiplayer/dedicated server host/client/server choice, no desync/corruption risk; FicsIt Remote Monitoring already serves live factory/power/train JSON over a local web server; official dedicated-server API can download saves with no mod.
Verdict: worth it only as a thin, optional, read-only bridge feeding the desktop app (later maybe markers pushed back). Don't move the planner in-game. If FRM JSON suffices, maybe no mod code at all.
A World Architect + Plan-vs-Actual (offline desktop): R3 Path 2 whole; player sets every goal; each autosave -> factual variance report (node extraction vs allocation, corridor flow vs budget, circuit headroom, idle/underclocked, snapshot diffs); never says what to build; on goal change solver only checks feasibility. Embraces saves/presets/manual, local files, fully offline. Leaves out live data, in-world display, suggestions. Why: favorite + monitoring, smallest risk, everyone can use it. Risk: autosave lag feels stale; factual reports must stay useful without becoming advice.
B Live-Linked Architect (desktop + bridge): desktop planner; live feed (FRM or own small mod) first-class; live dashboard, corridors light up under budget, nodes show real output; optionally committed sites/corridors exported as in-game map markers. Leaves out console, in-game UI beyond markers. Why: monitoring without autosave wait, plan visible in world. Risk: dependence on someone else's mod / SML pace; two-way link ~doubles multiplayer support work.
C In-Game Logistics Mod (fully vanilla+): planning terminal placed in base; world-scale planner + health panels; ghost outlines; warnings while playing; goals typed into terminal. Leaves out console, non-modders, solver depth, planning when game isn't running. Why: only honest version if you want a mod. Risk: full rewrite in unfamiliar stack; Unreal UI caps the planner; every patch freezes the whole product.
Rec: A, with World State designed so a live feed is just another source -> B is an add-on, first step a read-only FRM adapter. C only if being a vanilla+ mod is what excites you — a different project.
