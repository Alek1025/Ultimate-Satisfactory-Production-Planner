Opus R3 final:
a. P1 bridge = verified build-card loop: each step = machine count/recipe/clock rounded to friendly multiples (8x100% + 1x37.5%), belt/pipe tier per I/O, manifold fill-time warning, where to build (nearest free nodes, circuit to join, headroom), carry list. Blueprint hints ("3 copies of a 4-constructor blueprint"). Next autosave ticks off machines against the card; flags wrong recipe/clock/missing shard/orphaned circuit; always-on-top window shows current card. Placing is the player's job, checking is the app's.
b. P2 constraints that change WHERE: (1) discrete transport caps (belt/pipe/headlift step functions) -> refine at node and ship product vs ship raw; no calibration; (2) fuel-bound power generation — power lines have no capacity limit so the real question is siting generators near fuel/water/waste or spending corridor capacity on fuel; phase demand growth decides when to commit to nuclear; (3) one editable throughput budget per corridor (freight-car round trips/min, distance default, overridable) -> few trunks vs many spurs. Excluded: signal blocking, vehicle timing, exact truck fuel, fluid dynamics beyond caps/headlift. Without a save: same fixed map for everyone; node catalog + target is already a full problem.
Final paths:
1 Live Save Copilot — companion that watches autosaves, audits the real factory, tells you exactly what to build next. For mid-playthrough players with a messy running factory. Loop: autosave -> audit -> build card -> place in game -> next autosave verifies. Embraces save as authority, snapshot timeline, build/carry lists, always-on-top window, unlock awareness. Leaves out layout geometry and inter-site physics. Why: purest case for desktop; no web calculator does it; useful every session. Risk: save drift and inference errors erode trust.
2 World Logistics & Grid Architect — which nodes to claim, where to refine, how to move and power it across the map, phase by phase. For megabase planners / new-world starters thinking in regions and trunk lines. Loop: targets + node catalog (+ optional save) -> multi-site LP -> map of sites & corridors -> edit budgets -> re-solve per phase. Embraces node allocation, ship-product vs ship-raw, corridor sizing, power siting/phasing, sink/overflow policy. Leaves out interiors and vehicle sim. Why: answers WHERE, which existing tools don't model. Risk: too coarse to act on; every corridor needs a concrete buildable meaning ("2 cars, Mk5 unload").
3 Modular Factory Workbench — target -> buildable module schematic + commissioning checklist. For builders who care about clean repeatable factories. Loop: target -> solved module graph -> editable 2D schematic on foundation grid -> optimizer check -> commissioning order. Embraces layout, floors, startup, reusable module library. Leaves out world logistics and live save loop. Why: closes "numbers work" vs "I can build this". Risk: scope creep to CAD/3D; duplicating in-game blueprints.
Pick: P1. P3 most delight but biggest scope; P2 strongest intellectually but risks being admired and never built. Owner's question: "Is this app open WHILE YOU PLAY a world that already exists, or BEFORE YOU BUILD a world you're imagining?" While you play -> P1; before you build -> P2 if regions, P3 if buildings.
