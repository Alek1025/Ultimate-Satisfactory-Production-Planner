Sol R3 final:
a. Desktop for Workbench: plan is a file beside your save, copyable to another PC, opens offline on first launch; durable home for schematics, module library, revision history; crash recovery; solver jobs that keep running while in-game; return to the exact build revision you were following.
b. Perimeter: each external connection = labeled port + item/fluid + user-approved delivery/export rate; plus sustained power budget and separate startup allowance. Promises at the factory boundary; Workbench checks design against them and reports shortfalls by port/budget; player decides how the world meets them. Optional save import seeds unlocks and suggests budgets; rebase shows a diff, accept per update, accepted changes revalidate the schematic; user-edited budgets stay until replaced; facts vs estimates labeled.
Paths (shared: World State, local game data, observed vs inferred, inline reference, native HiGHS, propose/edit/check):
1 Live Save Copilot — open your save, find where the real factory falls short, get a build list for next session. Loop: watch autosaves, compare snapshots, flag bottlenecks, chosen fix -> build/carry list, check next save; compact companion window. Coverage: recipes, clocks, extraction, utilization, circuit headroom where evidence supports; routing/floorplans abstract. Why: every session gives new evidence; every recommendation has a real factory to check against. Risk: save shows starved machines but not which belt/junction caused it; make uncertainty visible.
2 World Logistics & Grid Architect — where production belongs, how freight moves, whether the grid supports each expansion. Loop: define sites/resources/corridors/phases, solve allocation & freight, stress-test delivery and power assumptions, choose what to build first. Coverage: train cycles, truck fuel, drone batteries, belt/pipe limits, headlift, power reserves/priorities; editable corridor budgets; factories as I/O blocks; saves optional. Why: answers costly siting/corridor/expansion-order decisions before committing. Risk: precise result hides shaky route assumption; show which budgets bind and sensitivity if they slip.
3 Modular Factory Workbench — target -> factory you can build from an editable schematic and start up in a known order. Loop: target + boundary budgets -> module proposal -> place/connect on foundation grid -> validate -> build from schematic + commissioning checklist. Coverage: reusable modules, ports, manifolds/balancers, tiers, floor transitions, materials, startup (priming, overflow); boundary connections; blueprint export deferred. Why: plan stays useful through construction. Risk: layout editing becomes a chore; modules and fast checks must save more effort than drafting costs.
Pick: Workbench. Owner's question: "Which decision should players open the app to make most often: what to fix in the factory they have, where to invest across the world, or how to build the factory they've planned?"
