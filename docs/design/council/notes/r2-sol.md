Sol R2: recommends Build-Ready Factory Workbench. Core loop: production target -> editable modules -> build and commissioning checklist; solver proposes and checks edits; save grounds design in a real world.
a. Schematic foundation grid with reusable modules: footprint, machine rows, labeled ports, manifold or balanced feed; belt/pipe tiers, crossings, floor changes, order to connect and start modules. Satisfactory Modeler already does splitter/merger math, so throughput math alone is weak; Workbench earns its place by turning a target into a layout you can revise, tally, reproduce. In-game Blueprint Designer handles reusable builds; defer .sbp export until printed/second-screen plan proves value.
b. Prioritize layout decisions that cause expensive rebuilds (rows, belt capacity, pipe feeds, startup, expansion space consistent when one input changes). World-scale's hard part is allocating scarce nodes/transport across sites. Workbench absorbs supply/freight/power budgets by phase; World Planner absorbs footprints and station interface sizing.
c. Save optional for design, authoritative for imported world facts. Same project for theorycraft and play; start with reference profile or explicit supply assumptions, compare with save, accept rebase. Randomized worlds need observed or confirmed nodes. Saves still need catalog for default nodes/well links. Ship starter profile only if redistribution permitted; otherwise manual inputs usable immediately + local catalog import.
Paths:
1 Copilot: open your world, get an actionable next build; follows autosaves, diffs unlocks/holdings/milestones, offers rebase; inventory-adjusted shopping list. Owns progression, inventories, audits, expansion. Audits from recipes, clocks, connected extractors, power config; label inferred vs observed. Risk: confident advice from incomplete data; keep last readable snapshot, show what a newer save invalidates.
2 World-Scale Logistics: decide where production belongs and what moves; claim nodes, allocate, compare phased maps; route budget = round-trip time, loading/buffers, fuel/batteries, belt/pipe limits at ends. Factory = footprint, ports, power demand, commissioning reqs. Risk: false precision on terrain/vehicle cycles/stations; editable estimates, surface assumptions.
3 Workbench: target -> factory you can build in sessions; modular starting layout, edit, see throughput/footprint/materials/power changes; export floorplan + ordered checklist with settings, belts/pipes, priming/startup, overflow. Owns declared inputs to outputs incl. sizing, manifold startup, load balancing, local power; codex entries alongside decisions; world logistics as supply/delivery budgets. Risk: schematic looks buildable but leaves physical decisions; prove with a fluid-heavy build and an expansion of an existing factory.
Keep from Opus: autosave diffs, reviewable rebases, inventory-adjusted shopping lists; Megabase site allocation + scenario comparison as distinct bet; Field Manual as in-workflow help.
