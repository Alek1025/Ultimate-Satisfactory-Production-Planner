Sol R4 (owner feedback round):
Verdict: build the offline World Logistics & Grid Architect; a vanilla+ mod is worth pursuing only as an optional, read-only companion.
Mod: an SML mod can observe machines and circuits live, show diagnostics on equipment, and put planned sites/corridor waypoints in the world; live data shows whether a bottleneck is sustained or a lull. FicsIt Remote Monitoring already exposes machine and circuit telemetry (getFactory, getPower) - evaluate before writing one. Costs: a second compatibility cycle (wait for SML and the mod after patches); Unreal/C++; testing across solo, hosted co-op and dedicated servers; install friction; consoles lack mods and console-PC crossplay is limited to unmodded sessions; the offline app still serves console players via presets/manual.
Paths:
1 World Logistics & Grid Architect (standalone): own targets from save/preset/manual; node allocation, refine-at-source vs ship-raw, fuel-bound power sites; editable corridor budgets; belt tiers, pipe limits, headlift, grid headroom per phase; autosaves show changes and plan-vs-actual. Leaves out interiors, train signalling, vehicle timing. Risk: false precision (saves omit default node attributes and well links; corridors still need an in-game terrain check).
2 Factory Operations Desk (desktop + live bridge): define sites, expected output, corridors; optional read-only mod feed tracks actual production and circuit headroom over time; autosaves as baseline when the feed is unavailable. Risk: attribution - knowing a site is short without knowing why.
3 Field Survey Planner (fully in-game mod): in-game panel to pin nodes/sites and sketch corridors, walk routes with waypoints, inspect nearby machines. Risk: a patch takes the whole planner offline; in-game UI eats time.
Recommendation: path 1, live telemetry as an optional input to the same project; evaluate the existing bridge before a custom mod.
