Opus Arch R1:
Frameworks: Electron with engine in utilityProcess (runner-up Tauri 2; same Chromium/WebGL on Win/Linux/Deck vs weak WebKitGTK; Node for file watch and future local HTTP bridge; no Rust). React 19 + Zustand, domain state outside React, map/readouts bypass React (runner-up SolidJS). HiGHS WASM in engine process, one cancellable job (runner-up native HiGHS CLI sidecar via MPS; switch only if MILP slow). PixiJS v8 map with custom camera, bitmap font atlas (runner-up deck.gl OrthographicView). uPlot charts + hand SVG gauges. Project file = one SQLite file (.wap via better-sqlite3): append-only event log, content-addressed blobs (snapshots, Docs model, results), WAL (runner-up zip of JSON + journal). Tests: Vitest on pure core with golden fixtures + fast-check properties (balance, caps, no double-claimed node); Playwright _electron ~5 E2E; missing fixtures FAIL unless ALLOW_MISSING_FIXTURES=1.
Architecture: GameData Library (Docs -> GameModel#hash, locale overlay, CatalogProvider: user-supplied pack | IoStore later | manual) -> Sources all implement Source -> ObservationBatch{facts, provenance, time}: SaveSource(watcher), PresetSource, ManualSource, LiveSource (Path 2: FRM JSON, DS API) -> World State = layer stack (default < inferred < observed < manual), branches = forks, rebase = reviewable ObservationDiff -> Plan model: Charter (phases, goals, pins, caps) + Network (sites, corridors, circuits), event-sourced commands -> revisions -> compile() -> immutable ProblemSpec (all inputs incl. engine/solver constants, catalog) fingerprint = hash(spec) -> Solver proposes -> Checker verifies whole buildings, real clocks, hard caps -> Variance engine pure (plan rev, snapshot[, prev]) -> Survey -> UI renderer over typed messages. Processes: main (windows, fs, watcher), engine utilityProcess (pure TS no I/O), renderer. Path 2: LiveSource = another Source, observed@time layer; marker export via Sink interface. §8: no re-keying, results under hash(spec) recomputed on import; fingerprint at compile time travels with job; spec includes everything; UI says "optimal within linear model" + Checker; Path 2 interfaces only; docs/adr/ required with design changes.
UI metaphor: as-designed vs as-built drawings. Plan = blueprint; each save = site survey; differences = REDLINES (facts). Player resolves each as amend plan / keep plan. Visual: cyanotype paper, white ink accepted, pencil-grey dashed proposals, red ink deviations. Shell: title bar breadcrumb (Project > Plan rev > World branch @ snapshot), watcher state, Docs hash; left rail 5 modes; status strip (fingerprint, solver state, crash journal). Screens: Charter (ledger goals x phases, pins, caps, objective order; right panel solver proposal as diff with checker results, binding limits; accept all/part/discard), Atlas (map canvas, sites black boxes, corridor stroke width = budget, contention rings, budget dial snapping to caps, sensitivity in inspector, phase timeline scrubber), Redline (as-built overlay with numbered clouds, variance list plan/save/Δ with observed/inferred badges grouped extraction/corridors/circuits/machines, since-previous diff), World (layer stack, fork, rebase diff review), Library (install, Docs import, catalog pack, unknown-class report). Surprises: autosaves as survey strip; drag corridor width to set budget with snapping detents; phase scrubber replays world; field-survey walk-the-map checklist for console players. Risk: default node catalog can't come from save; CatalogProvider via user-imported hash-verified pack, IoStore later.
Mockup: mockups/a1-opus.html (Atlas, Charter, Redline).
