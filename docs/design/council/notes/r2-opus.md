Opus R2:
a. Minimal built-world slice: each building as a record (class, recipe, clock, shards/sloops, position, node, power circuit). Nominal rates, extraction per node, power vs capacity per circuit. No belt/pipe topology in v1; flows inferred from summed nominal rates. Join on class names via Docs; unknown class = counted "unrecognized building". Belt tracing later, only for starved machines.
b. Save-less: not a separate mode. Everything is a World State (unlocks, nodes, built inventory, circuits). A save is one way to fill it; presets (Fresh start, Phase 3, Everything unlocked, fork of my save) are others. Plans sit on a World State; identical screens, only source badge differs. Theorycrafting = forking your world. Read Docs from detected install so nothing licensed is bundled.
c. Desktop-only: background folder watch (the Copilot loop); install discovery (Docs, saves, blueprints) avoiding licensing; native multithreaded HiGHS, no WASM 4 GB ceiling (MILP, multi-site, trains); persistent project DB with snapshot timeline/diffs; always-on-top companion window; .sbp blueprint read first, write later for simple modules.
Paths refined:
1 Copilot (keep + audit): "the planner that already knows your world". Loop: save in game -> audit (idle/underclocked, power headroom, extraction used vs available) -> optimizer proposes next target given what's built -> build list + carry list. Covers progression, audit, rebased plans, power circuits incl. fuel/startup, timeline. Leaves out layout and map-scale logistics. Risk: save churn, parse time on big saves.
2 World Infrastructure & Logistics (reshape): identity is logistics/power realism, not "map-first" (a map of claims is thin): train round-trip throughput, belt/pipe tiers incl. headlift, drone battery cost, truck routes, grid design (priority switches, batteries, sinks) as solver constraints across sites/phases; map is the canvas. Leaves out in-factory layout. Risk: transport modeling depth.
3 Build-Ready Workbench (drop Codex from name; codex is shared substrate in all paths built from user's Docs): logical 2D schematic — modules, explicit connections, manifold/load-balancer math, floors, footprint estimates, build checklist; blueprint import, later export. Risk: worse copy of in-game build mode; stay "what to connect and in what order".
Keep from Sol: optimizer as engine under all paths; "optimizer generates, human edits, optimizer checks"; explicit connections as first-class data; phases; layout is a distinct bet.
Recommendation: Path 1 (only path that requires desktop); World State makes theorycrafting first-class; build so Workbench can sit on top later (natural v2); Path 2's logistics/power as solver modules feeding both.
