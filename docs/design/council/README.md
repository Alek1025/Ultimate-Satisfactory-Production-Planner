These are the raw outputs of the design council that shaped the rewrite. The designers were Claude
Opus 5.5 and GPT-6.2 Sol, with Gemini 4 Hydrogen as mediator. Claude Fable 5.2 was planned for a
designer seat but couldn't run, so Opus took it. The settled results are in
[../direction.md](../direction.md) and [../architecture.md](../architecture.md); these files are
background.
