# Docs

- [design/direction.md](design/direction.md): what the rewrite is (World Architect + Plan-vs-Actual)
  and what was ruled out.
- [design/architecture.md](design/architecture.md): stack, processes, interfaces, World State,
  `.ussp` project file, UI design language and screens, milestones M0–M3, test invariants and the
  owner's decisions.
- [rewrite-notes.md](rewrite-notes.md): technical findings from v1 (save format, Docs parsing,
  solver, plans, map data, bugs to design out).
- [design/council/](design/council/): the design council's raw round notes and HTML mockups.

When a design decision changes, update `design/architecture.md` (or `direction.md`) in the same
change.
